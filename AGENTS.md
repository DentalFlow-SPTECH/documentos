# Dental Flow — documentação

Este repositório contém as fontes documentais do Dental Flow. `frontend`, `backend`, `infra` e `documentos` são repositórios Git independentes.

- Use `_brain/dental_flow_ap_clinic_SPC_index.md` para localizar uma fonte quando necessário. Leia apenas os assuntos pertinentes à tarefa.
- Especificações completas ficam em `0_Context`, `1_SPC`, `2_BPM`, `3_MER` e `4_Class`. As fichas do brain resumem e apontam para elas; não substituem requisitos.
- Distinga decisão confirmada, proposta, implementação atual e evidência executada. Não transforme demonstrações locais em contratos de API ou regras clínicas.
- Preserve identificadores de requisitos e a origem das informações. Uma mudança de arquitetura não aprova requisitos funcionais pendentes.
- Siga os nomes documentais definidos no README, sem data ou versão no nome. `README.md`, `AGENTS.md` e arquivos de configuração são exceções funcionais.
- Atualize as fontes afetadas e suas fichas na mesma entrega. Registre comandos e limites da validação; não copie transcripts, logs extensos ou credenciais para o brain.
- Preserve alterações concorrentes. Commit, push e publicação precisam de autorização explícita.
